# 1.0 stabilization plan

*Drafted 2026-05-27, right after Phase 5h.3 closed and the homelab hit the "core infra is up + monitoring + drift detection" milestone the design has been building toward. Captures the pre-build-on-top hardening pass before adding more services (Jellyfin, Immich, n8n, Privatebin, Startpage) on the foundation.*

## Framing

The homelab is at 1.0 — the foundation works. Phase 5h.3's drift-check baseline closed the last gap that made it merely *converged* rather than *self-aware*: any disagreement between Git and reality now surfaces as a Discord alert within 6 hours. Combined with VictoriaMetrics + VictoriaLogs + Zabbix catching runtime drift, the homelab tells the operator when something's wrong rather than waiting to be looked at.

What remains is character rather than core:
- **Phase 6 (Vault OIDC)** — operator-UX polish; humans still look up secrets in 1P
- **Phase 7 (jotunheim K3s)** — second failure domain + "can implode" learning sandbox
- **App backlog** (Jellyfin, Immich, n8n, …) — using the homelab, not building it
- **Phase 8b / 9** — refactors deferred by choice (Helm → vm-operator, ESO → Vault Agent)

Before any of those land, this plan hardens what's already deployed. The goal is **measurable confidence**, not neatness — each wave should leave the foundation more trustworthy, not just tidier. Cosmetic items are deliberately deferred unless they fall out of other work.

## Honest gap in the "1.0" framing

Failure-domain depth is the next axis of improvement and Phase 7 is the structural answer. Single cluster, single PG-leader-at-a-time, single NAS. This stabilization plan doesn't close those — they're explicit Phase 7 work. It hardens what we *do* have so that when we add services to it, we don't compound fragility.

| AppRole SecretID 90-day rotation — `ansible-local` + `ansible-awx` minted when? | 15 min | If either approaches 90d, rotate now while quiet |
| Authentik `django_channels_postgres` connection-churn vs Patroni VIP — benign noise or real symptom? | 30 min | authentik-server logs `"Postgres connection is not healthy" … OperationalError('consuming input failed: SSL SYSCALL error: EOF detected')` against the PG HAProxy VIP `10.0.10.210` at ~5/min, steady-state, while readiness stays green (observed 2026-05-30, incidental to the emptyDir cache migration — not caused by it). **Done criterion:** each item has either a "headroom is fine" datapoint or a follow-up task in the relevant phase backlog.

## Deferred — explicit "not now"

These are real, but they don't block "build on top of":

- **SSSD-for-SSH + Authentik LDAP outpost** — future identity phase; `ssh-users` group in `groups.yaml` is future-fit
- **Per-service Vault AppRole isolation** — wait until blast radius hurts
- **Self-hosted apt + tarball mirror** — post-Phase-5 commitment, significant standing infra
- **iSCSI node-record cleanup automation** — defer until enough migrations have happened to feel it
- **ESO → Vault Agent / VSO** = Phase 9 — long-term, pilot on jotunheim first

## Recommended sequence

1. **S1 (validation)** first — cheap, and might surface things that change downstream priorities
2. **S7 (fragility audit)** second — most likely to expose real issues before they bite during build-on-top
3. **S2 (recovery)** + **S3 (role debt)** in parallel — they don't conflict
4. **S4 (observability) / S5 (pins) / S6 (cleanup)** anytime

Estimated total: 2-3 sessions of focused work, not weeks.

## Definition of "done" for the 1.0 stabilization

When closed, this plan flips the homelab's posture from "everything works" to "everything works AND we can prove it works AND we'll know when it stops working." Concrete signals:

- Last `terraform plan` across every module: zero drift
- Last drift-check cycle: zero `changed=`
- Every recovery-critical artifact: documented out-of-band copy + verified-current
- Every alert path designed in: validated by a synthetic failure
- Every IaC version: concrete or has a decision row
- Every accumulated role-debt item: closed or has a follow-up phase

At that point, building on top of the homelab — Jellyfin, Immich, n8n, Phase 6, Phase 7 — is adding to a foundation we trust, not extending one we hope works.
